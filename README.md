# User Directory

A small React app (Vite) that fetches users from a public API and lets you search them by name or city.

Data source: https://jsonplaceholder.typicode.com/users

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Build

```bash
npm run build
```

## Concepts covered

- Splitting UI into components and passing props
- Fetching data with `fetch` inside `useEffect`
- Loading and error states
- Controlled input for search
- Filtering and rendering lists with `key`
